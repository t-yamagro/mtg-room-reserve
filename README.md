# 会議室予約システム

フロントエンド（HTML, CSS, JavaScript）のみで動作するシンプルな会議室予約システムです。

## 機能

- 2つの会議室（A, B）の予約管理
- 会議室の視覚的な選択
- 予約の重複チェック
- 予約データのローカルストレージ保存
- 予約データのCSVエクスポート
- レスポンシブデザイン

## 使用方法

1. `index.html`をブラウザで開きます
2. 会議室の画像をクリックするか、プルダウンから会議室を選択します
3. 予約フォームに必要事項を入力します
4. 「予約する」ボタンをクリックすると予約が完了し、CSVファイルがダウンロードされます
5. 予約一覧から予約の確認や削除ができます

## 技術スタック

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage API
- File API (CSVダウンロード)
